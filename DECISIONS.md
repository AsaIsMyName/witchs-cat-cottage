# Decisions

The history behind CLAUDE.md: what Asa decided, when, and why. CLAUDE.md holds only the current rules; read this when you need the reasoning, e.g. before reopening a settled question.

- **Oct 22, 2026 — PC first.** The game is designed for PC (mouse drag in a desktop browser); phones stay playable but untuned. This frees up screen space and allows smaller tiles and hover.
- **Oct 22, 2026 — Decorate above all, with magic.** The game moved from "clean, then decorate" to "decorate above all, with magic." Cleaning became one optional way to earn, not a step before decorating.
- **Oct 21, 2026 — The cat is a companion, not a judge** (after the milestone 2 playtest). A scored cat review made decorating feel like a puzzle with wrong answers, and didn't make Asa want to rearrange. The cat became an ambient companion that lives in the room while you decorate.
- **Oct 22, 2026 — Portal moments dropped** (milestone 3b). A version where the cat dove into the spellbook and floated behind its items was built and playtested. It didn't land: the cat mostly vanished behind an item with only a text bubble, so it never felt like it was playing with them.
- **Oct 21 → Oct 22, 2026 — Camera view.** First a front-facing room view (Oct 21), then replaced by a Stardew-style ¾ top-down view (Oct 22; milestone 4). Sizes set in milestone 4a, with a 9th floor row added after its playtest and the inventory book sized to fit its contents.
- **Oct 22, 2026 — Milestones 3–9 revised:** first for the magic theme, then to add the ¾ view as milestone 4.

## Answered open questions

- [x] Prop size: 16×16 or 32×32 pixels? → **16×16** (decided Oct 22, 2026): tiles are 16 art-pixels, drawn at 2× as 32px screen tiles.
- [x] Camera view? → **Front-facing room view** (decided Oct 21, 2026), then **replaced by a Stardew-style ¾ top-down view** (decided Oct 22, 2026; milestone 4).
- [x] Phone or PC? → **PC first**, with phones playable but untuned (decided Oct 22, 2026).
- [x] Does the cat have a name and personality, and should its reactions ever change? → **The player names it and picks a preset coat** (decided Oct 22, 2026); reactions stay fixed in v1.
- [x] Should there be a gentle goal, such as a "cat moments" journal collecting the reactions you've discovered? → **Yes, a scrapbook built in milestone 6** (decided Oct 22, 2026). Light completionist touch, not tied to coins at first; entry type decided at milestone 6 (see "Earning and unlocks").
- [x] Without a cat score, what drives coins and unlocks? → **Magic motes and cat gifts, plus optional cleaning, tuned so getting new items is never a bottleneck** (decided Oct 22, 2026). No incremental clicker. Amounts are tuned at milestone 6.
- [x] One room with themes, or several themed rooms? → **One room with separately switchable wallpaper and ground** (decided Oct 22, 2026).
- [x] Hosting: GitHub Pages or itch.io? → **GitHub Pages** (decided Oct 21, 2026). Every push to `main` deploys automatically.
